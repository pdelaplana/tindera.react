# Tech Stack

## Frontend
- **Framework:** React 19 (Ionic 8) for a robust, mobile-first UI experience.
- **Language:** TypeScript for strong type safety and developer productivity.
- **Mobile Bridge:** Capacitor 8 for native functionality and platform-specific deployments.
- **Data Management:** TanStack Query for efficient data fetching, caching, and synchronization.
- **Styling:** Styled Components for scoped CSS and Sass for global variables and theming.

## Backend & Infrastructure
- **BaaS Provider:** Supabase, providing PostgreSQL database, user authentication, and real-time capabilities.
- **API Communication:** Supabase-js for direct and typed interactions with the backend services.

## Tooling
- **Build Tool:** Vite for fast development and optimized production builds.
- **Quality Control:** 
  - Biome for extremely fast linting and formatting.
  - ESLint for complex architectural rules.
  - Vitest for unit testing.
  - Cypress for end-to-end (e2e) verification.
